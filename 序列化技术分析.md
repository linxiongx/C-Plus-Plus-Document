# 序列化技术分析

## 概述

本文档详细分析 CT 软件项目中的序列化技术。该项目采用二进制序列化方式，通过自定义的序列化框架实现配置数据、工作流程任务和设备状态的持久化。

### 2.2 基础类型序列化

项目使用模板函数实现基础类型的序列化：

```cpp
// 基础类型写入
template<typename _Ty>
void WriteData(CFile& aFile, const _Ty& data)
{
    aFile.Write(&data, sizeof(_Ty));
}

// 基础类型读取
template<typename _Ty>
BOOL ReadData(CFile& aFile, _Ty& data)
{
    if (sizeof(_Ty) != aFile.Read(&data, sizeof(_Ty)))
        return FALSE;
    return TRUE;
}
```

**支持的类型**：
- `BOOL`、`INT`、`UINT`、`DWORD`
- `DOUBLE`、`FLOAT`
- `size_t`、`ULONGLONG`
- `DWORD_PTR` (CPU 核心亲和性掩码)

### 2.3 CString 字符串序列化

```cpp
// 写入字符串 (长度前缀 + UTF-8 内容)
inline void WriteData(CFile& aFile, const CString& data)
{
    CStringA _data(data);                    // Unicode → ANSI 转换
    size_t len = _data.GetLength();

    aFile.Write(&len, sizeof(size_t));       // 写入长度前缀

    if (len > 0)
        aFile.Write(_data.GetBuffer(), len); // 写入实际内容
}

// 读取字符串
inline BOOL ReadData(CFile& aFile, CString& data)
{
    size_t len = 0;
    if (sizeof(size_t) != aFile.Read(&len, sizeof(size_t)))
        return FALSE;

    if (len == 0) {
        data = CString();
        return TRUE;
    }

    // 边界检查
    if (len > aFile.GetLength() - aFile.GetPosition())
        return FALSE;

    CHAR* _data = (CHAR*)malloc(sizeof(CHAR) * (len + 1));
    if (_data == NULL)
        return FALSE;
    _data[len] = '\0';

    int rLen = aFile.Read(_data, len);
    if (rLen == len)
        data = CString(_data);              // ANSI → Unicode 转换

    free(_data);
    return rLen == len ? TRUE : FALSE;
}
```

**序列化格式**：
```
┌────────────────┬─────────────────────────┐
│  len (8字节)   │   content (len 字节)    │
└────────────────┴─────────────────────────┘
```

### 2.4 std::vector 容器序列化

```cpp
// 写入向量
template<typename _Ty>
void WriteData(CFile& aFile, const std::vector<_Ty>& data)
{
    size_t cnt = data.size();
    aFile.Write(&cnt, sizeof(size_t));           // 写入元素个数

    if (cnt > 0)
        aFile.Write(data.data(), sizeof(_Ty) * cnt);  // 批量写入
}

// 读取向量
template<typename _Ty>
BOOL ReadData(CFile& aFile, std::vector<_Ty>& data)
{
    size_t cnt = 0;
    if (sizeof(size_t) != aFile.Read(&cnt, sizeof(size_t)))
        return FALSE;

    if (cnt == 0)
        return TRUE;

    // 智能处理：保留已有空间，跳过多余数据
    size_t cnt1 = min(cnt, data.size());
    if (cnt1 > 0) {
        UINT size = sizeof(_Ty) * cnt1;
        if (size != aFile.Read(data.data(), size))
            return FALSE;
    }

    // 跳过未读取的数据
    if (cnt > cnt1) {
        UINT size = sizeof(_Ty) * (cnt - cnt1);
        if (aFile.GetPosition() + size != aFile.Seek(size, CFile::current))
            return FALSE;
    }
    return TRUE;
}
```

**序列化格式**：
```
┌────────────────┬─────────────────────────────────────┐
│  cnt (8字节)   │   data[0] ~ data[cnt-1]            │
└────────────────┴─────────────────────────────────────┘
```

## 3. 配置序列化 (ConfigurationReadWrite)

### 3.1 基类实现

```cpp
// ConfigurationReadWrite.h
class ConfigurationReadWrite {
public:
    ConfigurationReadWrite(CString name);
    virtual ~ConfigurationReadWrite();

    void loadFile();   // 加载配置
    void saveFile();   // 保存配置

protected:
    virtual BOOL readData(CFile& aFile) = 0;
    virtual void writeData(CFile& aFile) = 0;

private:
    CString fileName;
};

// ConfigurationReadWrite.cpp
void ConfigurationReadWrite::loadFile()
{
    if (fileName.IsEmpty()) return;

    CString dirPath = ::GetParentDirectory(fileName);
    // 自动创建目录
    if (!PathIsDirectory(dirPath) && !MakeMultiDir(dirPath, 0))
        return;

    CFile aFile;
    if (!aFile.Open(fileName, CFile::modeRead | CFile::shareDenyWrite, &ex))
        return;

    readData(aFile);   // 调用子类实现
    aFile.Close();
}

void ConfigurationReadWrite::saveFile()
{
    // 类似实现，使用 modeCreate | CFile::modeWrite
    CFile aFile;
    if (!aFile.Open(fileName, CFile::modeCreate | CFile::modeWrite, &ex))
        return;

    writeData(aFile);  // 调用子类实现
    aFile.Close();
}
```

```cpp
// CPUDispatcher.h
class CPUDispatcher : public ConfigurationReadWrite {
public:
    DWORD_PTR CPU_GUI;                    // GUI 线程
    DWORD_PTR CPU_Detector_CallBack_Host; // 探测器回调主线程
    DWORD_PTR CPU_Detector_CallBack_Slave;// 探测器回调从线程
    DWORD_PTR CPU_HardwareStatusRefresh;  // 状态刷新
    DWORD_PTR CPU_ImageDisplay;          // 图像显示
    DWORD_PTR CPU_CTScanTask;             // CT 扫描任务线程
    DWORD_PTR CPU_CTDataTask;             // CT 数据处理线程

protected:
    virtual BOOL readData(CFile& aFile) override;
    virtual void writeData(CFile& aFile) override;
};

// CPUDispatcher.cpp
BOOL CPUDispatcher::readData(CFile& aFile)
{
    if (!::ReadData(aFile, CPU_GUI)) return FALSE;
    if (!::ReadData(aFile, CPU_Detector_CallBack_Host)) return FALSE;
    if (!::ReadData(aFile, CPU_Detector_CallBack_Slave)) return FALSE;
    if (!::ReadData(aFile, CPU_HardwareStatusRefresh)) return FALSE;
    if (!::ReadData(aFile, CPU_ImageDisplay)) return FALSE;
    if (!::ReadData(aFile, CPU_CTScanTask)) return FALSE;
    if (!::ReadData(aFile, CPU_CTDataTask)) return FALSE;
    return TRUE;
}

void CPUDispatcher::writeData(CFile& aFile)
{
    ::WriteData(aFile, CPU_GUI);
    ::WriteData(aFile, CPU_Detector_CallBack_Host);
    ::WriteData(aFile, CPU_Detector_CallBack_Slave);
    ::WriteData(aFile, CPU_HardwareStatusRefresh);
    ::WriteData(aFile, CPU_ImageDisplay);
    ::WriteData(aFile, CPU_CTScanTask);
    ::WriteData(aFile, CPU_CTDataTask);
}
```

## 7. 序列化技术的优势与局限

### 7.1 优势

| 特性 | 说明 |
|------|------|
| **二进制格式** | 读写速度快，文件体积小 |
| **类型安全** | 模板函数确保类型匹配 |
| **跨版本兼容** | 通过长度前缀实现字符串安全读写 |
| **自动目录创建** | 配置加载时自动创建缺失目录 |
| **错误处理** | 每步读取都有返回值检查 |

### 7.2 局限

| 问题 | 说明 |
|------|------|
| **版本兼容** | 二进制格式难以跨版本兼容 |
| **调试困难** | 无法直接查看序列化内容 |
| **缺少压缩** | 大数据文件体积较大 |

## 9. 关键技术点总结

1. **模板方法模式**: `ConfigurationReadWrite` 基类定义序列化骨架，子类实现具体读写逻辑

2. **模板函数**: `ReadData`/`WriteData` 模板函数支持任意基础类型

3. **特化处理**: 对 `CString` 和 `std::vector` 进行特化处理

4. **长度前缀字符串**: 字符串序列化使用长度前缀，支持边界检查

5. **智能向量读取**: 向量读取时保留已有空间，只读取新数据

6. **错误恢复**: 每个 `ReadData` 调用都有布尔返回值，失败即返回

7. **自动目录创建**: `loadFile`/`saveFile` 自动创建缺失的父目录

### 11.5 继承体系序列化设计原则

| 原则 | 说明 |
|------|------|
| **基类提供默认空实现** | `Detector::readData()` 返回 `TRUE` 但不做任何事 |
| **子类必须显式调用基类** | 使用 `BaseClass::readData(aFile)` 显式调用 |
| **调用顺序：基类 → 子类** | 先序列化基类字段，再序列化子类字段 |
| **错误即返回** | 任何 `ReadData` 失败立即返回 `FALSE` |
| **命名空间区分** | 使用 `::ReadData` 调用全局函数，避免与类方法冲突 |



## 十二、优化建议

## 版本兼容性（最高优先级）

当前二进制格式最大的痛点是**没有版本号**，字段增删会导致旧文件无法读取。

**建议在每个配置文件头部写入版本号：**

cpp

```cpp
// 在 ConfigurationReadWrite 基类中添加
struct FileHeader {
    DWORD magic   = 0x43544346; // "CTCF" 魔数，用于校验文件类型
    UINT  version = 1;          // 当前版本号
};

void ConfigurationReadWrite::saveFile() {
    FileHeader header;
    ::WriteData(aFile, header);
    writeData(aFile);
}

BOOL ConfigurationReadWrite::loadFile() {
    FileHeader header;
    ::ReadData(aFile, header);
    if (header.magic != 0x43544346) return FALSE; // 文件类型错误
    return readData(aFile, header.version);        // 将版本号传入子类
}
```

子类根据版本号做**条件读取**，实现向后兼容：

cpp

```cpp
BOOL CPUDispatcher::readData(CFile& aFile, UINT version) {
    if (!::ReadData(aFile, CPU_GUI)) return FALSE;
    // ...
    if (version >= 2) {
        // 新增字段，旧文件跳过，使用默认值
        if (!::ReadData(aFile, CPU_NewField)) return FALSE;
    }
    return TRUE;
}
```
